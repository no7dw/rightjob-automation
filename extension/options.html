本地服务（JSeeker Service）是本项目自带的后端进程，负责调用模型并保管 API Key、本地 OCR 截图识别、记录 JD 日志与耗时（可选 LangSmith trace）。 评分和自动沟通都依赖它，不是可选项。

推荐顺序：① 启动本地服务 → ② 在「模型」中配置 Provider 与 API Key → ③ 导入简历。

本地 OCR 需要先在项目目录运行 npm run helper:build（仅 macOS）。 状态显示「本地未就绪」时，构建后重启服务即可。

首次使用：在项目目录运行 ./restart.sh（或 npm run helper）。 服务启动后扩展会自动配对，无需手动填写 Token；点击「刷新状态」可重新检测。

模型（LLM）

使用你自己的模型服务（BYOK）。Provider 与 Model 来自本地目录并自动联动；API Key 可在此覆盖项目根目录 .env 中的值。Key 只保存在本机扩展存储并发送给本地服务，不会回显或进入导出。
